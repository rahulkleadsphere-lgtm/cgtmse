# CGTMSE Guarantee Coverage Slabs & Ceilings

## 1. Maximum Ceiling
The maximum guarantee cover available per borrower enterprise is **₹500 lakh (₹5 Crore)** for manufacturing and general service enterprises. For Retail Trade and Educational Institutions, the maximum ceiling is **₹200 lakh (₹2 Crore)**.

## 2. Coverage Percentages Summary Table

| Category / Borrower Segment | Credit Facility Range | Extent of Guarantee Cover |
| :--- | :--- | :--- |
| **Micro Enterprises** (General) | Up to ₹5 Lakh | **85%** of the sanctioned credit facility |
| **Micro Enterprises** (General) | Above ₹5 Lakh up to ₹50 Lakh | **75%** of default amount |
| **Micro Enterprises** (General) | Above ₹50 Lakh up to ₹500 Lakh | **75%** of default amount |

| **ZED Certified MSEs** | Up to ₹500 Lakh | **85%** across all loan slabs |
| **Retail Trade** | Up to ₹50 Lakh | **85%** |
| **Retail Trade** | Above ₹50 Lakh up to ₹200 Lakh | **75%** |
| **Agniveer Entrepreneurs** | Up to ₹500 Lakh | **85%** across all loan slabs |

## 3. Hybrid Security Scheme (Collateral + Guarantee)
Under the Hybrid Security product, MLIs can obtain collateral security for a part of the credit facility, while the unsecured portion (up to ₹500 lakh) can be covered under CGTMSE guarantee, enabling larger composite funding structures.
